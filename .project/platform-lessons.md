# Platform Lessons

A running log of platform-specific extraction problems encountered and how they were resolved. Each entry helps determine whether a fix is a **one-off** (single article edge case) or a **recurring pattern** that should become a permanent strategy in the extractor.

## How to use

After fixing a platform extraction issue, append an entry below. Use the same `problem_category` value when the same type of issue appears again. When any category reaches **3 occurrences**, it should be proposed as a candidate for codifying into the platform extractor code.
