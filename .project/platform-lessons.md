# Platform Lessons

> **Community-maintained.** Anyone using Noosphere can contribute. When your Claude agent fixes a platform extraction issue, it records the lesson here. If you submit a pull request with your entry, every user benefits from what you learned.

A running log of platform-specific extraction problems encountered and how they were resolved. Each entry helps determine whether a fix is a **one-off** (single article edge case) or a **recurring pattern** that should become a permanent strategy in the extractor.

## How to use

After fixing a platform extraction issue, append an entry below using the template. Reuse the same `Category` slug when the same type of issue appears again. When any category reaches **3 occurrences**, it becomes a candidate for codifying into the platform extractor (see `.project/platform-extractors.md`).

## Entry template

```markdown
### YYYY-MM-DD — <platform>
- **Problem**: <one-line description>
- **Cause**: <why it happened>
- **Fix**: <what was done>
- **Category**: <kebab-case slug>  ← reuse for similar issues
- **Contributor**: @github-handle
- **Verdict**: one-off | recurring (count: N)
```
