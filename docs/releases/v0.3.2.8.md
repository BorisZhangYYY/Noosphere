# Noosphere v0.3.2.8

Released 2026-09-30.

## Highlights

- Full-text search results now open the matching article context with a brief fine red underline in both themes.
- Search excerpts preserve Markdown structure, links, tables, code and local images.
- Batch capture, workspace navigation, article text backups and collection description flows received layout and reliability fixes.
- Firecrawl no longer sends `waitFor` for WeChat articles, preventing the 408 failure described in Issue #35.

## Verification

- Frontend tests and production build pass.
- Python source compilation and crawler payload regression checks pass.
- Light and dark theme search navigation was visually checked in the local test environment.
