# v0.3.3.2 — 编辑器、工作区排序与引用气泡

发布日期为 2026-10-14。正式发布记录见 [GitHub Release](https://github.com/BorisZhangYYY/Noosphere/releases/tag/v0.3.3.2)。

## 改动

- 整体块和列表手柄统一放在最左列，当前列表项手柄紧贴右侧；两者均保留两列六点，整体手柄增加分组轮廓和淡背景。左侧留白、嵌套列表和块间空隙保持连续命中，长编号与手柄互不遮挡。
- 知识工作区支持同级类别排序及类别内文章排序，顺序持久保存。允许区域、插入线与禁止反馈明确限制拖动范围；文章不能拖入其他类别或正文编辑器，排序保留 AI 分类来源和文章内容。键盘、CLI 和 MCP 使用相同规则。
- 引用原句点击或轻触后，在右上方打开带尖角的注释气泡。移开鼠标后仍保持打开；气泡内可以进入 Markdown 编辑和预览，长注释独立滚动。点击空白、再次点击原句、关闭按钮或按 Escape 关闭。
- 全文搜索仅索引审阅后的正文和标题，不包含批注、感悟、原始抓取稿或来源元数据。旧索引自动移除此前的其他字段，结果统一显示正文片段。
- 搜索进入文章后，所有命中词持续高亮；浏览器直接绘制高亮，快速滚动时与文字同步并随正文裁切，避免遮住顶部栏。编辑或离开搜索目标时清理高亮。
- 类别和文章目录行的导航箭头统一贴齐右侧，窄屏和悬停状态保持一致。

## 升级

```bash
docker pull ghcr.io/boriszhangyyy/noosphere:v0.3.3.2
```

现有文章、个人感悟和引用注释保持独立存储。排序数据独立于 AI 分类；搜索索引为可重建派生数据，升级后首次搜索会自动清理旧字段。CLI / MCP 的 `all` 范围兼容为正文搜索，其他已移除的范围会返回明确错误。
