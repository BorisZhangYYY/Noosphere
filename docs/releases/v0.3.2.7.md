# Noosphere v0.3.2.7

本次将可靠性修复、全文搜索和批量工作台首版统一发布。

## 新功能

- **全文搜索**：搜索标题、作者、正文、感想和批注；原文可单独选择。支持中文双字词、中英文关键词、短语查询、分类及子分类、来源和日期筛选。结果按文章分组，显示高亮摘要，并可在文章内打开片段上下文。支持搜索索引重建。
- **批量工作台**：粘贴链接或导入文本，每批最多 100 条。预检无效链接、批内重复和已收录文章；支持仅抓取或抓取后 AI 校对、目标分类、逐项进度、暂停、继续、取消待处理项、单项或全部失败重试，以及失败链接导出。
- **内容镜像状态**：文章侧栏显示同步状态，失败后可手动重试。镜像补充完整清单与校对报告，可恢复单个丢失文件。

## 修复与优化

- 保留未保存草稿，避免打开感想、刷新数据或保存过程中继续输入时丢失内容。
- 使用内容版本校验和文章锁，拒绝过期保存；AI 请求期间文章发生变化时，拒绝覆盖新内容。
- 永久删除加入持久标记，清理失败后不会从镜像恢复已删除文章，并保留删除重试入口。
- 后台任务持久化、并发和队列限制；重启后标记中断任务，避免自动重复上传。
- 分类变更立即刷新文章归属，文章列表增加缓存、分页与筛选。
- 拆分编辑器与主题资源，减少首屏加载的样式体积。
- 修复独立容器的默认文章目录，使用可写的 `/data/articles`。

## 升级前必读

1. Docker Compose 现在要求设置 `NOOSPHERE_ACCESS_TOKEN` 和 `NOOSPHERE_DATABASE_PASSWORD`。已有 PostgreSQL 数据目录须先使用原数据库密码；修改环境变量不会自动修改数据库密码。
2. 浏览器登录用户名可用 `noosphere`，密码为访问令牌；MCP/REST 使用 Bearer 令牌。默认仅向本机开放应用端口，不再向宿主机公开 PostgreSQL 端口。
3. 程序化替换文章正文必须携带读取时的内容版本；缺少版本返回 428，版本冲突返回 409。CLI 使用 `--expected-revision`，MCP 使用 `expected_revision`。
4. 升级前停止服务并备份完整数据目录。内容镜像不包含完整图片与运行状态，不能替代完整备份。

详细操作见 [升级指南](../reliability-upgrade.md) 和 [搜索与批量工作台](../search-and-batches.md)。

## 首版边界

- 搜索使用本地索引，在查询时核对文件变化；片段展示上下文，尚不自动滚动到渲染正文中的段落。
- 批量任务默认跳过已收录文章，批内逐项执行，共享服务并发限制。模型配置变化会阻止后续阶段继续；暂停和取消等待正在执行的阶段结束。
- 批量任务不自动上传；费用预算、外部上传防重复、自动限流退避和完整配置快照留待后续。
- 验证使用隔离数据与模拟模型，未调用用户的模型 API，不作万篇文章性能承诺。

## 验证

226 项后端与浏览器测试、4 项前端草稿测试通过；完整版本镜像通过 PostgreSQL、搜索、保存冲突、批量任务重启恢复和 Chromium 检查。

```bash
docker pull ghcr.io/boriszhangyyy/noosphere:v0.3.2.7
```

发布镜像目标架构为 Linux amd64；本次不宣称提供原生 arm64 镜像。
