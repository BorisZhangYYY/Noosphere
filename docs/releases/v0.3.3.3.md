# v0.3.3.3 — 实时审阅、任务历史与图片操作

发布日期为 2026-10-17。正式发布记录见 [GitHub Release](https://github.com/BorisZhangYYY/Noosphere/releases/tag/v0.3.3.3)。

## 改动

- 在知识工作区的文章详情中连续展示 AI 审阅正文，支持自动跟随、暂停跟随及跨页面继续查看。没有正文时保持空白，输出完成后再切换到已保存文章，保留阅读位置。
- 二次审阅先清空预览，生成过程中不会闪回旧稿；可中途取消并恢复原有正文、图片、元数据、分类和审阅次数。成功后统一保存，保护其他窗口已经保存的修改。
- 保留现有工作台和 Noosphere 背景。当前任务只显示排队及运行中的任务，完成、取消和失败任务自动进入历史；抓取失败可重试。文章页发起的审阅、上传和感悟润色也会同步到工作台。
- 抓取与审阅显示实际处理阶段，删除按流事件次数累加的虚假百分比。先提供未分组文章，再在审阅成功后完成分类；兼容状态 `awaiting_review` 表示审阅已保存，无需额外确认。
- 所有图片均有独立六点拖拽手柄，包括小图及同一段内的相邻图片。已移除图片默认隐藏，主动显示后仍可移动，并在保存、重开后保留位置；移动不会恢复图片，也不会把它放入上传正文。
- 删除工作区拖拽警告和无效的 Command+K 提示，调整工作区、抓取菜单对齐及批量输入样式。
- 识别知乎登录、访问受限及缺少正文的页面，尝试备用抓取器；仍无正文时停止，不再创建虚假文章或发起 AI 审阅。

## 升级

```bash
docker pull ghcr.io/boriszhangyyy/noosphere:v0.3.3.3
```

使用该镜像标签更新现有部署，并保留原数据卷。升级后刷新已打开的网页，以加载新版交互；入口页面会重新校验缓存。

原始抓取稿、个人感悟和引用注释保持独立存储，无需手工迁移文章。服务重启前应先等待运行中的任务结束。反向代理允许实时连接时使用事件流，不可用时网页自动回退到轮询。

接入任务 API 的客户端应允许运行中抓取／审阅任务的 `progress` 为 `null`，根据 `stage` 显示状态；任务保存完成后进度为 `100`。

## 使用说明

实时输出会复用已完成的 Markdown 块，减少长文重复渲染。模型分段之间尚未返回新正文的空档仍会等待；更广泛的长文结构去重与重组保留为后续优化。
