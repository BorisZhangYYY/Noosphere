# v0.3.3.1 — 文章块操作与标题折叠

版本准备于 2026-10-13，开发分支为 `codex/v0.3.3.1`。本页记录待发布版本；正式标签、GitHub Release 和镜像发布尚未执行。

## 改动

- 编辑模式中，段落、引用、表格、代码、分隔线和完整列表可按块移动。拖动显示插入线，靠近阅读区域边缘时平滑滚动，按 Esc 可取消。
- 左侧留白也能直接选中对应块，沿行间空隙和嵌套列表移动鼠标时保持连续识别。
- 列表显示两个紧凑入口：内侧六点手柄移动当前项及其子内容，外侧列表图标移动整组。悬停时边框明确展示移动范围；编号、项目符号和任务复选框保持可见。
- 正文标题支持折叠，范围到下一个同级或更高级标题为止，包含子标题及其内容。展开时只移动标题，折叠后移动完整章节。
- 折叠只是显示状态，不删除 Markdown，不产生未保存改动。父章节展开和移动后保留子章节的折叠状态；重复标题在撤销、重做和后续输入时仍对应正确内容。
- 目录、搜索和引用跳转可展开隐藏的目标。阅读模式保持连续全文布局；重新打开文章时默认展开。
- 移动保留原有 Markdown 格式、链接、图片、表格、代码、引用定义及选区，支持撤销、重做、保存和重新打开。既有图片保护和保存冲突检查继续生效。

## 使用

进入文章的「编辑」模式，在正文块或左侧留白处悬停，拖动相应手柄。聚焦手柄后可按 Alt + 上下方向键移动，也可点击手柄使用方向按钮；手机上先点击内容块，再点击对应手柄。

标题左侧的三角形用于折叠和展开。文章总标题保持固定。列表项暂时只在同一父列表内排序，跨列表移动和改变缩进留待后续版本。

详细操作见 [文章编辑器](../article-editor.md)。
