# Noosphere v0.3.2.7-fix

这是 v0.3.2.7 的界面与访问体验修复版，不增加新的业务范围。

## 主要修复

- 浏览器不再弹出原生 Basic Auth 对话框。Web 端改为 Noosphere 站内登录页，成功后使用 HttpOnly 会话 Cookie；MCP、REST 和兼容命令行客户端仍可使用 Bearer 或 Basic 认证。
- 知识工作区的“+”统一提供单篇抓取与多篇批量入口。批量表单、预检、任务历史和移动端布局使用同一套视觉与交互规则。
- 搜索结果不再显示图片语法、链接地址、元数据行和 Markdown 标记；清理前后高亮位置保持一致，包括删除元数据行和 Unicode 字符的情况。
- 修复短文章在阅读模式下出现大块空白、移动端打开抓取弹窗后侧栏仍停留、菜单无法通过点击外部或 Escape 关闭，以及单篇抓取关闭按钮误提交等问题。
- 全局复查登录、首页、搜索、批量、设置、知识工作区、分类和文章页面的明暗主题与桌面/平板/手机布局，统一间距、表单、空状态、焦点和横向溢出表现。

## 安全边界

- 配置 `NOOSPHERE_ACCESS_TOKEN` 后，远程浏览器可以先加载登录页，但受保护的 API 与 MCP 仍需认证。
- 未配置访问令牌时，远程请求仍被拒绝；只有本机可以打开 Web 工作区。
- Web 会话 Cookie 不保存访问令牌原文，认证状态响应禁止缓存。

## 升级

继续沿用 v0.3.2.7 的数据目录、数据库密码和访问令牌即可，不需要数据迁移。详细凭据与备份说明见 [v0.3.2.7 升级指南](../reliability-upgrade.md)。

```bash
docker pull ghcr.io/boriszhangyyy/noosphere:v0.3.2.7-fix
```

Python 包元数据使用兼容 PEP 440 的 `0.3.2.7+fix`；Git 标签、GitHub Release 和容器标签使用 `v0.3.2.7-fix`。
